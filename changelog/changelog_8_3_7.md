# cad_engine 变更记录（2026-08-03 至 2026-08-07）

> 本文档记录本周完成的最终用户可见功能变化。

## 维护规则

- 每周使用一个 changelog 文件，按日期分节追加最终用户可见变化。
- 每次功能修改或一组相关调整合并为一条记录，不记录中间尝试、重启、部署或刷新操作。
- 本周结束后，将本文件作为周记录归档；下周新建对应日期范围的周记录。

## 2026-08-07

### 1. 首页导航图标与视觉统一

- 首页左侧导航的八个入口替换为指定 SVG 图标，统一按导航栏空间控制尺寸。
- 图标颜色统一使用展开后文字颜色，不再使用灰色；折叠和展开状态保持一致。
- 导航按钮、展开后的内部按钮和底部设置入口同步调整尺寸与间距。

### 2. 上传资料与 1.1 分阶段解析

- 上传文件后点击发送箭头只执行本地 OCR；进入 1.1 点击“AI 解析并带入字段”后才调用 AI。
- 1.1 解析过程中按钮显示处理中提示，完成后将结果带入空字段并保留已有人工填写内容。

### 3. AI 推荐默认值与 1.2 确认展示

- AI 推荐覆盖所有必填字段；BOM 装配等字段不再被错误设置为必填。
- 非必填字段保持为空，不再填入低价值的待人工确认或低置信度默认值。
- 下拉枚举字段只能推荐系统已有选项，不能由 AI 创造新条目；推荐值、置信度和低置信度提示在 1.2 显式展示。

### 4. 解析状态与推荐可追溯性

- 1.1 和 2.1 的解析按钮统一显示处理中状态，避免用户无法判断任务是否仍在执行。
- AI 带入结果保留来源和状态提示，产品类型等空的必填字段也纳入统一推荐流程，不再只修复单个字段。
